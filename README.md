# 口袋服务器 PocketServer

**让闲置 Android 手机或电视，成为身边的局域网文件服务器。**

PocketServer 是一个运行在 Android 手机、平板和电视设备上的文件共享应用。设备连接同一个局域网后，可以通过电脑浏览器访问共享目录，上传、下载和管理文件；也提供 WebDAV 和 FTP 兼容方式，方便不同设备接入。无需注册账号，也无需经过第三方云服务器中转。

> 当前开源源码基于 **V1.2.0** 交付版本。功能和兼容性会受 Android 版本、设备厂商、网络环境和存储权限影响。

## 可以用来做什么？

- **手机和电脑互传文件**：把照片、视频、文档或安装包放入共享目录，在同一 Wi-Fi 下用电脑浏览器访问；也可以从电脑上传文件到手机。
- **利用闲置手机**：把旧手机接入家庭网络，作为临时文件中转站，为自己或家人的设备提供共享目录。实际可用空间取决于手机存储及系统权限。
- **电视和电视盒子取文件**：在 Android TV 或盒子上运行应用，通过电视界面查看服务状态，再用电脑传入视频或其他文件，减少插拔 U 盘的次数。
- **家庭内整理照片和资料**：在可信的家庭网络中，从电脑访问手机上的共享文件夹，集中复制、整理旅行照片或日常资料。
- **临时办公或会议传资料**：在可信的办公局域网中，用浏览器交换演示文稿、图片和文档，接收端无需单独安装桌面客户端。
- **兼容现有文件工具**：支持 WebDAV 的客户端可尝试将共享目录作为网络位置使用；只支持 FTP 的旧设备或软件可以使用 FTP 兼容服务。具体操作和兼容性因客户端而异。
- **设备之间交换文件**：通过附近设备发现、配对及传输功能，在支持的 PocketServer 设备间交换文件；实际发现效果取决于局域网是否允许设备互访与多播。

## 功能概览

- **浏览器访问**：在局域网内通过网页查看共享目录、上传和下载文件，支持二维码提供访问入口。
- **配对连接**：网页主通道通过六位配对码建立连接；设备端可查看连接状态。
- **多种访问方式**：HTTP 网页、WebDAV 和 FTP，按使用的设备和客户端选择。
- **手机与电视界面**：同一应用面向手机和 Android TV，运行时适配相应界面。
- **文件传输管理**：提供传输记录、任务控制及断点续传等功能；效果取决于具体传输通道和设备环境。
- **本地网络使用**：文件传输设计为在设备所在网络中完成，不需要云端账号。

## 快速开始

1. 在 Android 手机或电视上安装自行构建的 APK，打开 PocketServer。
2. 根据应用提示选择共享目录并授予所需存储权限，然后启动服务。
3. 让访问设备与 Android 设备连接到同一可信局域网。确保路由器没有开启阻止设备互访的隔离设置。
4. 在电脑浏览器打开应用显示的地址。网络支持 mDNS 时也可尝试 `http://pocketserver.local:8080`；若无法解析，请使用应用显示的 IP 地址。
5. 根据提示输入设备上显示的配对码，即可访问共享文件。FTP 和 WebDAV 的入口与设置以应用界面为准。

不同 Android 设备对后台运行、电池优化和存储访问的限制不同；服务中断时，请检查应用权限、后台限制、Wi-Fi 与设备互访设置。

## 安全与使用边界

**请只在可信局域网中使用，不要把服务直接暴露到互联网。** 当前版本未启用 TLS，HTTP、WebDAV 和 FTP 的内容可能被同网设备监听。FTP 兼容服务无需用户名和密码；开启时，同网设备可能访问共享内容。请选择合适的共享目录，避免共享敏感文件，不使用时关闭服务。配对码不能替代加密传输。

PocketServer 适合本地文件交换，不应作为唯一备份。重要文件请保留独立备份。实际速度、稳定性和后台运行时间取决于设备、网络和 Android 系统设置。

## 开发与构建

项目采用 Kotlin、Jetpack Compose 和 Android Gradle Plugin，源码配置如下：

| 项目 | 要求或版本 |
| --- | --- |
| Android 最低版本 | Android 7.0（API 24） |
| 编译 SDK | API 35 |
| JDK | 17 或更高，目标字节码为 17 |
| Android Gradle Plugin | 8.6.1 |
| Kotlin | 2.0.20 |
| Gradle | 8.7 |

使用 Android Studio 打开项目，安装 Android SDK Platform 35。源码包未包含 Gradle Wrapper 的脚本和 JAR，需先安装 Gradle 8.7，并在项目根目录生成 Wrapper：

```bash
gradle wrapper --gradle-version 8.7
./gradlew assembleDebug
./gradlew testDebugUnitTest
```

Windows 上将 `./gradlew` 换成 `gradlew.bat`。调试 APK 通常位于 `app/build/outputs/apk/debug/`。Android Studio 也可以配置本机 SDK；`local.properties` 是本地文件，不应提交。

正式版本签名材料未包含在仓库中。自行发布时请使用自己的密钥并妥善保管。原始项目中保留了 JVM 测试及网页测试工具；本次开源整理没有重新执行构建或真机测试，使用前请在目标设备上验证。
